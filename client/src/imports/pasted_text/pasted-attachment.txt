# ACASHIELD – COMPLETE UI/UX DESIGN SYSTEM & APPLICATION DESIGN BRIEF

## ROLE

You are an award-winning Senior Product Designer, UX Researcher, Design Systems Architect, SaaS Designer, and Enterprise Software Design Expert.

Your task is to design a **complete, production-ready UI/UX** for **AcaShield**, a modern Progressive Web Application (PWA) for academic institutions.

The final output should be indistinguishable from a commercial SaaS product used by leading universities around the world.

The designs should be implementation-ready for React + Vite + Tailwind CSS + shadcn/ui.

# PROJECT OVERVIEW

## Product Name

**AcaShield**

## Tagline

**Securing Academic Integrity**

---

## PRODUCT DESCRIPTION

AcaShield is a centralized academic project repository and localized plagiarism detection platform.

It enables universities to:

* Manage final year project submissions
* Detect plagiarism against locally archived projects
* Archive institutional research
* Enable supervisors to review projects
* Generate originality reports
* Search historical research
* Preserve institutional knowledge

The system is built for universities and research institutions.

The primary users are:

* Students
* Supervisors
* Administrators

# DESIGN PHILOSOPHY

This is a **Mobile-First Progressive Web Application (PWA).**

Everything must be designed for mobile first before expanding naturally to larger devices.

The experience must progressively adapt to:

1. Android Phones (Primary)
2. iPhones
3. Tablets
4. Laptops
5. Desktop Computers
6. Large Displays

Do NOT create a desktop-first interface.

Desktop should simply reveal more information while preserving the same interaction model.
